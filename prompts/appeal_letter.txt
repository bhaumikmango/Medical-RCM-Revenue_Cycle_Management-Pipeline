## CARC-Specific Counter-Argument Instructions
Follow ONLY the instruction block that matches CARC {carc_code}:

[CARC 29 — Timely Filing]
- State the date of service and the date the claim was received.
- If delay_reason_code is present: cite it explicitly as justification 
  for the late filing and argue the filing window exception applies.
- If delay_reason_code is absent: argue based on insurance_type filing 
  limits (Medicare = 365 days, Commercial = 90-180 days) using the 
  exact dates from the claim.
- If insurance_type is Medicare and PatientRelationship is secondary: 
  state that the timely filing window begins from the primary payer EOB 
  date, not the service date, and request reconsideration on that basis.

[CARC 16 — Missing Information]
- List each missing field from the evidence array by name.
- State that the missing documentation has been attached to this appeal.
- Request reprocessing upon receipt of the attached materials.
- Do not speculate about why the information was missing originally.

[CARC 18 — Duplicate Claim]
- If ClaimFrequency is 7 or 8: explicitly state this is a corrected or 
  replacement claim, not a duplicate submission, and cite the frequency 
  code as evidence.
- If ClaimFrequency is 1: request the payer identify the original claim 
  reference number that triggered the duplicate flag, as no duplicate 
  was submitted by this provider.

[CARC 50 — Medical Necessity]
- Cite the principal diagnosis code and its clinical description.
- Argue the clinical alignment between the diagnosis and the procedure.
- Reference any prior authorization present in the evidence.
- If no prior auth: acknowledge and argue that the clinical documentation 
  supports medical necessity independent of prior authorization.

[CARC 197 — Prior Authorization Absent]
- Acknowledge the prior authorization was not obtained pre-service.
- Argue eligibility for retroactive authorization based on the clinical 
  urgency or circumstances evident in the diagnosis codes.
- Request the payer's retroactive authorization review process be applied.

[CARC 252 — Attachment Required]
- State that the required attachment has been included with this appeal.
- List what type of documentation is being submitted based on the 
  procedure code and diagnosis.
- Request reprocessing upon receipt.

## Hard Rules — You Must Follow These
1. Only use facts present in the Claim Information and Supporting Evidence 
   sections above. Do not invent authorization numbers, physician names, 
   clinical notes, or dates not provided.
2. Never mention confidence scores, system analysis labels, or internal 
   RCM terminology (e.g., "recoverability", "CARC category") in the letter.
3. The counter-argument paragraph must be 3-5 sentences. Not shorter, 
   not longer.
4. The full letter must not exceed 400 words.
5. Use formal medical billing language throughout.
6. Do not output anything before "Date:" or after "Gabeo RCM Billing Team".
